Helmet middleware for Pulsar. This middleware is a wrapper around the Express
[`helmet`](https://github.com/helmetjs/helmet) library helping to secure
Pulsar applications by setting various HTTP headers.

## Installation

<PackageManagers>
	```bash # install with npm npm install @pulsar/helmet ```
</PackageManagers>

## Usage

```typescript
import { Pulsar } from 'pulsar';
import { helmet } from '@pulsar/helmet';

const app = new Pulsar().use(helmet());
```

## Options

The `helmet` middleware accepts options from the Helmet library. See their
[documentation](https://github.com/helmetjs/helmet/blob/95bd2cc6045551048b8af305702996982d6ea7eb/README.md)
for more information on the available options.

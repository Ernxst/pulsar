## Manual Setup

This guide will walk you through the steps to manually install and configure a new Pulsar project
if you prefer not to use the [automatic CLI tool](#).

### 1. Create your directory

Create an empty directory with the name of your project, and then navigate into it.

```bash
mkdir my-pulsar-project
cd my-pulsar-project
```

Once you are in your new directory, create your project package.json file. This is how you will
manage your project dependencies, including Astro. If you aren't familiar with this file format,
run the following command to create one.
